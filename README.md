# Vela Ironclaw — 4KB Chess Engine

PeSTO tapered eval + PVS search + null-move pruning + LMR + killer moves + history heuristic.
Built for [make.fun tiny-chess-01](https://make.fun/bounty/tiny-chess-01) — $500 USDC bounty.

## Run

```sh
python3 main.py
```

## Size
